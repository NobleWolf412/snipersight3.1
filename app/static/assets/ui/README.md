# Local cockpit assets

- `house.svg`, `radar.svg`, `chart-candlestick.svg`, `book-open.svg`,
  `flask-conical.svg`, `settings-2.svg`: Lucide static 1.45.0, ISC license in
  `LUCIDE-LICENSE.txt`.
- `inter-500.woff2`, `inter-600.woff2`: Latin normal Inter from
  `@fontsource/inter` 5.3.0, OFL license in `INTER-LICENSE.txt`.

Selected source files are checked in. No network request or npm install is
needed to render them. Existing logo, Inter 400, and the bundled chart remain
under their existing provenance.
